📒 담임노트+ 사용 설명서

핸드폰으로 톡톡 기록하고, PC에서 정리하는 초등 담임 노트

담임노트+는 초등 담임 선생님을 위한 무료 웹앱이에요. 회원가입이 없고, 개발자 서버도 없어요.

  • 📱 핸드폰: 교실에서 번호 누르고 버튼 하나로 관찰 기록·출결 메모·일정을 남겨요.
  • 💻 PC: 모인 기록을 학생별로 보고, 통지표 참고 글 복사·엑셀로 받기, 자리·모둠 배치, 학교 일정·시간표 정리를 해요.
  • ☁️ 동기화: 선생님 본인 구글 드라이브의 숨김 폴더로 핸드폰 ↔ PC 기록이 저절로 오가요. 학생 이름은 올라가지 않아요.

1처음 시작하기

💻 PC

  1. 크롬(또는 엣지)에서 담임노트+ 주소를 열어요.
  2. 왼쪽 메뉴 ⚙️ 설정에서 학년·반·학생 수를 넣고 저장해요.
  3. (선택) 👦 학생 관리에 이름을 넣으면 PC 화면에 이름이 함께 보여요. 이름 없이 번호로만 써도 돼요.

📱 핸드폰

  1. 크롬(아이폰은 사파리)으로 주소를 열어요.
    카톡·스레드 안에서 링크를 누르면 그 앱 안의 브라우저로 열려요. 그 안에서는 앱 설치와 구글 연결이 안 되니, 화면에 뜨는 크롬으로 열기를 눌러 주세요.
  2. 첫 화면 맨 위 앱 설치하기를 눌러 바탕화면에 아이콘을 만들어요.
    • 버튼이 안 보이면: 크롬 ⋮ → 설치 및 바로가기 만들기(또는 홈 화면에 추가)
    • 아이폰: 사파리 공유(□↑) → 홈 화면에 추가 — 아이폰은 꼭 추가해 주세요. 추가하지 않고 쓰면 오래 안 열었을 때 기록이 지워질 수 있어요.
    • 아이콘에 작은 크롬 표시가 붙어도 괜찮아요. 기능은 똑같아요.
  3. 바탕화면 아이콘으로 열고 학생 수를 넣은 뒤, “이 기기는 핸드폰이에요”를 체크하고 시작해요.

☁️ 핸드폰과 PC 잇기

  1. PC: 🔄 핸드폰 연결 → 구글로 연결
  2. 핸드폰: ⚙️ → 구글 드라이브 → 구글로 연결
  3. 두 기기 모두 같은 구글 계정으로 연결해요.
처음 연결할 때 “Google에서 확인하지 않은 앱” 화면이 나오면 고급 → 담임노트+(으)로 이동 → 허용을 누르세요. 담임노트+는 선생님 드라이브의 앱 전용 숨김 폴더만 쓰고, 다른 파일은 볼 수 없어요.

2핸드폰으로 기록하기

첫 화면에는 큰 버튼이 있어요: 📝 관찰 기록 🗓️ 출결 🏆 보상 📌 일정. 위쪽 날짜를 바꾸면 그날 기록으로 남아요.

📝 관찰 기록

  1. ① 번호를 눌러요. 여러 명을 한꺼번에 골라도 돼요.
  2. ② 상황 버튼(참여·관계·태도)을 누르면 바로 저장돼요.
  3. 버튼에 없는 내용은 아래 ✏️ 직접 쓰기에 써서 저장해요. 예: 3번 → “활동 후 뒷정리를 잘함”
  4. 잘못 눌렀으면 아래에 잠깐 뜨는 되돌리기를 눌러요.
🤝 다툼은 자리·모둠과 이어져요. 다툰 두 학생을 함께 고르고 “친구와 다툼”을 누르거나, 5번을 고르고 직접 쓰기에 “7번 학생을 때림”처럼 번호를 쓰면, PC 자리·모둠 화면에 “5번 ↔ 7번 떼어 놓기” 추천이 떠요. 떼어 놓을지는 선생님이 정해요.

🗓️ 출결

  1. ① 번호 → ② 유형(결석·지각·조퇴·결과, 지각·조퇴·결과는 몇 교시인지도 골라요) → ③ 사유(질병·미인정·출석인정·기타) → 저장
나이스 입력 전 확인용 메모예요. 공식 출결은 나이스에 입력하세요. 병명 같은 구체적 사유는 적지 말고 분류만 남겨 주세요.

📌 일정

  • ＋ 일정 넣기: 갑자기 잡힌 회의 등을 넣어요. 날짜는 [오늘·내일·모레], 시간은 [아침 8:30·점심 12:40·3시·4시]를 누르거나 직접 골라요.
  • 핸드폰에서 넣은 일정은 구글로 연결돼 있으면 PC 학교 일정에도 들어가요.
  • 끝난 일정은 앞의 칸을 체크하면 목록에서 숨겨져요. 아래 “완료한 일정 보기”로 다시 볼 수 있어요.
  • 🕘 오늘 시간표는 일정 화면에서 눌러 펼쳐 봐요. (PC에서 주간학습안내를 가져오면 생겨요)

3PC에서 정리하기

메뉴할 수 있는 일
👦 학생 관리번호·이름(선택)·성별·학습 특성 입력. 엑셀·한글 표를 복사해 한꺼번에 붙여 넣기 가능
🗓️ 출결 메모달별 출결 표, 칸을 눌러 고치기, 월 요약 복사(나이스 마감 대조), 📥 ○월 엑셀 / 학년도 전체 엑셀
📝 관찰 기록PC에서도 빠른 기록·직접 쓰기. 학생별 기록을 기간(이번 달·학기·학년도)별로 보고, 📋 복사로 통지표 참고 글 만들기, 📥 엑셀로 받기, 상황 버튼 편집
🪑 자리·모둠학생 수만 넣어도 번호로 자동 배치. 학습수준·리더·남녀·시력 고려, 갈등 관계(떼어 놓기)·필수 동행, 관찰 기록 다툼 추천, 배치 저장·인쇄
📅 학교 일정월중행사 가져오기(한글 .hwp/.hwpx), 주간학습안내 가져오기 → 시간표(간단히/자세히), 달력·목록 보기, 우리 학년만·내 담당만, 일정 직접 추가, 첨부 파일
🔄 핸드폰 연결구글 연결·지금 동기화. 구글 없이 파일로 옮기는 방법도 있어요
💾 백업기록 백업(JSON), 파일 포함 백업(ZIP), 복원, 학생 명단 CSV
⚙️ 설정화면 스타일, 맡은 일(담임·교과전담), 학년·반·학생 수, 담당자 이름(“내 담당” 표시용)
📋 통지표·생활기록부 쓸 때: 관찰 기록 → 학생 고르기 → 기간 “이번 학기” → 📋 복사. 상황별 횟수와 날짜별 기록이 줄글로 복사돼요. 반 전체를 한 번에 보려면 📥 엑셀로 받기.

🏆 보상 — 칭찬 점수 · 모둠 점수 · 학급 온도계 · 숙제 검사

PC 메뉴 🏆 보상, 핸드폰 첫 화면 🏆 보상에서 써요. 벌점은 없고 칭찬만 쌓여요.

  • ⭐ 개인: 번호를 고르고 발표·친구 도움 같은 이유를 누르면 +1점. 점수판에서 학생을 누르면 기록을 보고 보상을 쓸 수 있어요(예: 급식 먼저 먹기 10점). 보상을 쓰면 그만큼 점수가 줄어요.
  • 👥 모둠: 모둠마다 +1·+2·+3. 👑은 이번 주에 가장 많이 받은 모둠이에요. 자리·모둠에서 배치를 저장해 두면 모둠원 이름도 보여요. ↺ 모두 0으로로 새로 시작할 수 있어요.
  • 🌡️ 학급 온도계: 반 전체가 잘하면 +1°·+3°·+5°. 목표 온도(기본 100°)가 되면 학급 보상(예: 영화 보는 날)을 하고 다시 0°부터 시작해요.
  • 📚 숙제 검사: 숙제 이름을 쓰고 검사 시작 → 낸 학생 번호를 누르면 안 낸 학생이 바로 나와요. “낸 학생에게 칭찬 점수 +1”을 켜 두면 점수도 함께 쌓여요. 이번 달 2번 넘게 안 낸 학생도 알려 줘요.
  • 📺 칠판에 크게 보기: 교실 TV에 학급 온도계와 모둠 점수를 크게 띄워요.
  • 🎁 보상 목록 편집에서 보상 이름과 점수를 우리 반에 맞게 바꿔요. “학급” 첫 줄의 점수가 온도계 목표 온도예요.
핸드폰에서 준 점수·숙제 검사도 구글 동기화로 PC에 모이고, PC의 점수판·보상 목록은 핸드폰에도 들어가요.

📚 교과전담 선생님이라면

  1. 처음 열 때 교과전담을 고르세요. (이미 쓰고 있다면 ⚙️ 설정 → 맡은 일에서 바꿔요.)
  2. PC 📝 관찰 기록 → ＋ 반 관리에서 맡은 반을 넣어요. 예: 3-1 과학 24명, 3-2 과학 26명. 핸드폰에서는 관찰 기록 위의 ＋ 반으로도 넣을 수 있어요.
  3. 수업 중에는 반 고르기 → 번호 → 상황 버튼. 담임 화면처럼 3초면 돼요.
  4. 성적 처리 때는 PC에서 반을 고르고 학생을 누른 뒤 📋 복사 또는 📥 엑셀로 받기. 반마다 따로 모여 있어요.
교과전담 화면에서는 출결·학생 관리·자리·모둠 메뉴를 숨기고, 상황 버튼은 수업 장면(참여·탐구·협력·태도) 위주로 바뀌어요. 반별 이름 명단은 명단 버튼으로 붙여 넣을 수 있고, 이 PC에만 저장돼요.

4구글 동기화 알아두기

  • 핸드폰: 기록하면 몇 초 뒤 저절로 올라가요.
  • PC: 켜져 있으면 5분마다 저절로 받아요. 바로 보고 싶으면 지금 동기화.
  • 구글 로그인은 1시간 유지돼요. 앱을 새로 열었을 때 “[동기화]를 눌러 이어 주세요”가 보이면 동기화를 한 번 눌러 주세요.
  • 오가는 것: 핸드폰 → PC는 관찰·출결 기록, 핸드폰에서 넣은 일정, 완료 체크 / PC → 핸드폰은 학교 일정, 시간표, 상황 버튼, 학년·학생 수
  • PC는 한 대를 주 PC로 써요. 다른 PC에서 연결하면 “이 PC를 주 PC로 바꿀까요?”라고 물어요. 취소하면 그 PC는 핸드폰 기록을 받기만 해요.

5백업과 설정

  • 기록은 사용하는 브라우저 안에 저장돼요. 브라우저 데이터를 지우거나 PC를 바꾸면 사라질 수 있으니 💾 백업에서 가끔 백업 파일을 받아 두세요. 오래 안 받으면 위에 알림이 떠요.
  • 첨부 파일까지 옮기려면 파일 포함 백업(ZIP)을 쓰세요.
  • 화면 스타일: ⚙️ 설정에서 귀여운 · 딸기우유 · 레몬소다 · 포도젤리 · 맑은 하늘 · 민트 · 블랙&오렌지 · 네이비 중에 골라요. PC와 핸드폰은 따로 정할 수 있어요.
  • 업데이트는 저절로 돼요. 새 버전이 나오면 앱을 열 때 바뀌고 “✨ 새 버전으로 바뀌었어요”가 잠깐 떠요. 글을 쓰는 중에는 기다렸다가 바꿔요. 핸드폰은 앱을 화면으로 다시 불러올 때도 새 버전을 확인해요.

6개인정보 안내

  • 입력한 기록은 개발자에게 전송되지 않아요. 광고도 없어요. (앱이 몇 번 열렸는지만 이름·쿠키 없이 세요)
  • 구글 드라이브에는 번호·날짜·상황만 올라가요. 학생 이름, 담당 교직원 이름, 메모, 첨부 파일은 올라가지 않아요.
  • 핸드폰 화면에는 학생 이름이 나오지 않아요(번호만).
  • 학생 정보는 학교의 개인정보 관련 규정에 맞게 관리해 주세요.

자세한 내용은 개인정보처리방침을 보세요.

7자주 묻는 질문

핸드폰 기록이 PC에 안 들어와요.
① 두 기기가 같은 구글 계정인지 ② 핸드폰에서 동기화를 눌렀을 때 “기록 ○건 보냄”이 뜨는지 ③ 핸드폰이 카톡 안 브라우저가 아닌지(크롬/설치한 앱) ④ 핸드폰 ⚙️에서 “이 기기는 핸드폰이에요”가 체크돼 있는지 확인한 뒤, PC에서 지금 동기화를 눌러 보세요.
“[동기화]를 눌러 이어 주세요”가 계속 떠요.
구글 로그인이 1시간 지나 끊긴 거예요. 동기화를 한 번 누르면 다시 이어져요. 기록은 그대로예요.
핸드폰을 바꿨어요.
새 핸드폰에서 설치하고 같은 구글 계정으로 연결하면 PC의 일정·시간표가 들어와요. 옛 핸드폰에서 보내지 않은 기록이 있다면 먼저 옛 핸드폰에서 동기화해 주세요.
PC 화면이 좁아서 핸드폰 화면처럼 나와요.
핸드폰 화면의 ⚙️ → PC 화면으로 보기를 누르거나 창을 넓혀 주세요.
상황 버튼을 우리 반에 맞게 바꾸고 싶어요.
PC 관찰 기록 → 상황 버튼 편집에서 고치거나 새로 만들어요. 동기화하면 핸드폰에도 똑같이 들어가요.
새 기능이 안 보여요 (업데이트가 안 돼요).
앱을 완전히 닫았다가(핸드폰은 최근 앱 목록에서 위로 밀어 닫기, PC는 창 닫기) 다시 열어 보세요. 그래도 그대로면 한 번 더 열어 주세요. 바뀌면 “✨ 새 버전으로 바뀌었어요”가 잠깐 떠요. 기록은 지워지지 않아요.
돈이 드나요?
무료예요. 회원가입도 필요 없어요.
