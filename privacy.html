📒 담임노트+ 개인정보처리방침

시행일: 2026년 9월 28일 · 앱 주소: https://olivemiso-lab.github.io/damimnote-plus/

담임노트+ 개발자는 사용자의 어떤 개인정보도 수집하거나 저장하지 않습니다. 모든 기록은 선생님의 기기에, 그리고 선생님이 선택한 경우 선생님 본인의 구글 드라이브에만 저장됩니다.

1. 담임노트+는 무엇인가요

초등 담임교사가 학교 일정, 학생 관찰·출결 메모, 자리·모둠 배치를 관리하는 무료 웹앱입니다. 회원가입이 없고, 개발자가 운영하는 서버가 없습니다.

2. 기록이 저장되는 곳

  • 입력한 학생 명단, 관찰·출결 메모, 일정, 첨부 파일은 사용하는 브라우저 안(localStorage, IndexedDB)에만 저장됩니다.
  • 개발자에게 전송되는 정보는 없습니다. 광고, 사용 통계·분석 도구를 쓰지 않습니다.
  • 브라우저 데이터를 지우면 기록도 지워지므로, 앱의 [백업] 메뉴로 백업 파일을 받아 두시기 바랍니다.

3. 구글 드라이브 동기화 (선택)

핸드폰과 PC의 기록을 맞추기 위해 사용자가 직접 [구글로 연결]을 누른 경우에만 동작합니다.

  • 요청하는 권한: https://www.googleapis.com/auth/drive.appdata 하나입니다. 이 권한으로는 담임노트+가 사용자의 구글 드라이브에 만든 앱 전용 숨김 폴더의 파일만 읽고 쓸 수 있으며, 드라이브의 다른 파일은 볼 수 없습니다.
  • 드라이브에 저장되는 내용: 관찰·출결 기록(학생 번호, 날짜, 상황·유형), 학교 일정, 시간표, 관찰 상황 버튼, 학년·반·학생 수. 학생 이름, 담당 교직원 이름, 메모, 첨부 파일은 올리지 않습니다.
  • 연결한 계정의 이메일 주소: 어떤 계정으로 연결했는지 화면에 보여 주기 위해 사용자의 기기에만 저장합니다.
  • 로그인 권한(액세스 토큰)은 사용 중인 브라우저 탭에만 약 1시간 보관되며 개발자에게 전송되지 않습니다.
  • 드라이브와 주고받는 데이터는 사용자의 브라우저와 구글 사이에서만 오가며, 개발자의 서버를 거치지 않습니다.

담임노트+가 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 준수합니다. 받은 정보는 위의 동기화 기능에만 사용하며, 제3자에게 제공하거나 광고에 사용하지 않습니다.

4. 연결 끊기와 삭제

  • 앱의 [핸드폰 연결] 또는 핸드폰 ⚙️ 설정에서 [연결 끊기]를 누르면 동기화가 멈추고 로그인 권한이 취소됩니다. 기기의 기록은 그대로 남습니다.
  • 구글 계정 설정의 서드파티 앱 및 서비스에서 담임노트+의 액세스를 삭제할 수 있고, 구글 드라이브 설정의 [앱 관리]에서 담임노트+의 숨김 데이터를 삭제할 수 있습니다.
  • 기기의 기록은 브라우저의 사이트 데이터를 지우면 삭제됩니다.

5. 학생 개인정보에 관한 안내

학생 정보는 교사가 학교의 개인정보 관련 규정에 따라 입력·관리해야 합니다. 핸드폰에서는 학생 이름 없이 번호로만 기록하며, 출결 사유는 분류(질병·미인정 등)만 적도록 안내합니다. 공식 출결은 나이스에 입력하세요.
